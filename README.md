## 怎么读

每本书有自己的目录，每章可以单独打开阅读，也可以沿章节底部的导航依次读下去。以后新增作品时，会在这里增加入口，不要求它们采用同一种题材或写法。

## 关于创作

选题和创作方向由我提出，AI 协助构思、起草与整理。作品会随新的想法继续修改。

不同作品采用不同的叙述方式，具体说明见各书目录。虚构故事中的人物、对话与情节不作为现实事件的记录或指控。
