# 聚光灯背后

你坐进化妆间，第一次发现镜头里的一张脸，需要多少人共同交付。你拿到想演的角色，却发现现实里的一句「不」，比剧本里的告别更难说出口。你终于被更多人认识，一顿临时起意的晚饭却开始需要安排。

这本书从一个念头开始：如果能与一位知无不言的演员或明星深聊，除了镜头前的答案，你还想听见什么？

十个独立章节，把这些问题写成典型化的假设场景。它们关注工作怎样被组织、机会怎样被选择，以及那些安排落到一个人的生活里，会变成什么。

## 怎么读

- **按顺序读**：从身体与形象，进入角色与选择，再到走红后的生活，最后看机会背后的规则与价格。[从第一章开始 →](01_交付一张脸.md)
- **按兴趣读**：直接选择下面的一章。各章没有连续剧情，不必记住前一章的人物与经历。
- **读完继续**：章节末尾有上一章、下一章和目录入口；每章内部用少量小标题分隔场景，方便暂停和回来。

## 创作说明

本书采用第二人称叙事。「你」是各章独立设置的虚构角色，不对应同一位演员，也不影射具体公众人物。

人物、对话、流程和冲突均属于典型化假设场景，用来展开对工作机制与生活选择的思考。场景不代表行业中的统一惯例，不是采访、爆料或真实案件还原，也不提供医疗、法律等专业建议。

目录、编号与阅读入口的组织方式参考了 [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)。本书不复制其正文，也不采用它的知识指南与证据分级结构。
