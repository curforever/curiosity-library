# 原来如此

我们习惯了考试、缴费、排队和打分，却不常追问：为什么偏偏这样安排？它解决了谁的问题，又把什么留给了另一个人？

这本书从日常疑问出发。先读一个短故事，再看懂背后的机制；也看看换一个处境，原本合理的选择会怎样变样。

## 按生活领域读

大章归纳一类生活问题，小节是一篇独立故事。不必按顺序读，也不必先知道概念名称。目录随新文章增加。

## 每篇里有什么

故事中的选择与后果，带出日常安排背后的逻辑。“原来如此”解释它为什么起作用，以及何时不够用；“再想一步”只改变一个条件，让问题继续向前走。

我们关心常见解释里容易被省略的人：手头没有余钱的人、身体提前吃不消的人、承担后果却不能决定规则的人。具体篇章选择真正影响判断的角度，不把每件事写成阴谋或风险清单。

## 创作说明

人物与情节为虚构，用来说明机制，不代表真实案例或普遍发生的频率。涉及现实制度、数据和专业知识时，篇末列出事实依据与核实日期，并说明故事的简化之处。

解释一种安排的由来，不意味着赞同它的所有结果；指出代价，也不意味着替代方案没有代价。
